# Auditoría de dependencias (npm audit) — 2026-11-13

Re-corrida de `docs/NPM_AUDIT_2026-10-06.md`, más de un mes y varios PRs
después (incluyendo el módulo Caja). Mismo alcance: solo dependencias de
producción (`npm run audit:prod` = `npm audit --omit=dev`).

## Qué cambió desde octubre

- **`zod` 4.1.11 → 4.6.6** (vía `overrides`, sin tocar `@vercel/blob`) —
  hallazgo nuevo desde octubre: "Zod can exhaust memory while validating
  oversized constrained collections" (alto). Este `zod` no es una
  dependencia directa de Nelyx — vive 3 niveles adentro de
  `@vercel/blob → @vercel/oidc → @vercel/cli-config`, código interno de
  Vercel para resolver credenciales OIDC, nunca expuesto a input de un
  usuario de Nelyx. Igual se corrigió: el bump queda dentro del mismo
  major (4.x) y no tocó ninguna línea de la app — cero riesgo de romper
  algo, mismo criterio que los overrides de `sharp`/`source-map-js` de
  octubre.
- Los dos hallazgos de octubre que ya estaban resueltos (`sharp`,
  `source-map-js`) siguen resueltos.
